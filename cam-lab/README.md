# CAM Lab — изолированная проверка CAM-движка

Эта папка — экспериментальная площадка. Рабочий `index27.html` не изменяется.

## Цель

Проверить [OneManLabs CAM](https://github.com/OneManLabs/cam) как основу CAM-расчёта для CNC PRO 3D:
- импорт SVG: открытые и замкнутые path, polyline, stroke, fill, группы и transforms;
- контурная гравировка по центральной линии;
- V-carve;
- выборка залитых областей (pocket);
- точечные операции;
- симуляция снятия материала с учётом формы инструмента;
- экспорт G-code (пока только для тестов, не для подключения к станку).

## Почему выбран этот кандидат

OneManLabs CAM — браузерное приложение на React, Three.js и TypeScript. В upstream README заявлены SVG/DXF, contour/pocket/drill, depth passes, 3D toolpath preview, симуляция снятия материала в Web Worker и GRBL G-code.

Лицензия upstream — MIT. При распространении заимствованного кода нужно сохранять уведомление об авторских правах и текст лицензии. Это отдельный проект, не часть основной сборки CNC PRO 3D.

Зафиксированная версия upstream: `66eba04bc576d0432ec5cb512cb6a8d73c4dedc1`.

## Подготовка

Требуется Git и Node.js 22 или новее.

Из корня репозитория запустить:
```powershell
powershell -ExecutionPolicy Bypass -File .\cam-lab\setup-engine.ps1
```

Затем:
```powershell
cd .\cam-lab\engine
npm run dev
```

Открой локальный адрес, который напечатает Vite.

## Тестовый сценарий

1. Импортировать исходный SVG без предварительной конвертации.
2. Убедиться, что открытые линии остаются открытыми, а залитые области распознаются отдельно.
3. Сравнить contour, V-carve и pocket на одном и том же файле.
4. Выбрать инструмент с известной геометрией и проверить ширину/глубину канавки.
5. Запустить 3D-симуляцию и сравнить остаток заготовки с ожидаемым результатом.
6. Проверить границы заготовки, ноль, безопасную высоту и глубину проходов.
7. Сохранить SVG и настройки теста, чтобы сравнивать последующие версии.

## Ограничения и безопасность

- Этот стенд не подключён к рабочему интерфейсу CNC PRO 3D.
- Не отправлять тестовый G-code на станок.
- Неизвестный контроллер пока не позволяет выбрать безопасный постпроцессор.
- Перед интеграцией проверить единицы, масштаб, ориентацию осей, ноль, геометрию фрез и корректность симуляции.
- CAM-движок будет интегрироваться только после успешных тестов и проверки лицензии/зависимостей.
